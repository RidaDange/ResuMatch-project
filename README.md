# ResuMatch 🎯

### Smart Resume Analysis & Job Matching Platform

ResuMatch is a web-based resume analysis tool that helps job seekers tailor their resumes for specific job roles. It compares a resume with a given **Job Description (JD)** and provides insights into **job alignment, keywords, tone, clarity, and overall resume quality**.

## ✨ Features

* 📄 Resume & Job Description analysis
* 🎯 Resume-JD matching
* 🔑 Keyword analysis
* 📊 Compatibility / ATS-style scoring
* ✍️ Tone & clarity analysis
* 🕒 Analysis history
* 🔐 User authentication
* ☁️ Cloud-based AWS backend

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript
**Backend:** Python, AWS Lambda
**Cloud & Deployment:** AWS, Amazon CloudFront
**Tools:** Git, GitHub, VS Code

## 🔄 How It Works

**Upload Resume → Enter Job Description → Analyze → Get Score & Insights → Improve Resume**
